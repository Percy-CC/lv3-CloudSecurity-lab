# 雲端安全模擬器 (Cloud Security Simulator) v0.2.3

供香港中學生使用的純前端雲端安全教學模擬器。學生以雲端管理員身份觀察監控及日誌，辨識攻擊，再使用控制台工具修正設定。

> 教學用途；與任何雲端供應商無關。流量、費用及攻擊均為模擬，不連接真實雲端服務。本頁沒有外部函式庫或網絡請求。

## 檔案結構

| 檔案 | 說明 |
|---|---|
| `index.html` | 模擬器本體，包含 HTML、CSS、JavaScript 及繁體中文／英文 `I18N` |
| `README.md` | 使用及部署說明 |
| `project.md` | 架構、遊戲規則及設計文件 |
| `scenarios.md` | 九種攻擊的修正條件及情境答案 |
| `log.md` | 版本記錄、修正及測試結果 |

## 本機使用及部署

直接以瀏覽器開啟 `index.html` 即可。本專案不需安裝、建置或啟動伺服器。

部署至 GitHub Pages：

1. 將上述檔案放在 repository 根目錄。
2. 在 repository 的 **Settings → Pages** 選擇 `Deploy from a branch`、`main` 及 `/(root)`。
3. 儲存後使用 GitHub Pages 提供的網址。

### 語言

開始畫面頂部的 **English／中文** 按鈕可切換介面語言。選擇會儲存在瀏覽器的 `localStorage`（鍵 `cs_lang`），重新載入後仍會沿用；排行榜日期使用 `YYYY-MM-DD` 格式。

## 正式遊戲

1. 在開始畫面輸入暱稱、班別代碼及種子 (Seed)，選擇難度；預設為「簡單」。
2. 每局固定 300 秒（5 分鐘），起始預算 HK$400。首個攻擊在第 15 秒出現。
3. 留意首頁資源狀態及事件通知；進入資源控制台後查看「概覽監控」及「日誌查看」。
4. 在「回報事件」選擇攻擊，再用正確工具修改設定並按「套用」。
5. 時間完結、預算用盡、平均健康度低於 20%、全部本局攻擊已解決或自行結束時，顯示結果及排行榜。

同一種子及難度會產生相同攻擊種類及次序；次序盡量交替網絡層與應用層。各局只從九種攻擊中抽取該難度 quota 的數量，不保證每局都出現全部九種。

### 難度

| 參數 | 簡單（預設） | 普通 | 困難 |
|---|---:|---:|---:|
| 遊戲時長 | 300 秒 | 300 秒 | 300 秒 |
| 首個攻擊 | 第 15 秒 | 第 15 秒 | 第 15 秒 |
| 攻擊 quota | 5 | 7 | 9 |
| 攻擊間隔 | 45–60 秒 | 30–45 秒 | 20–35 秒 |
| 同時有效攻擊上限 | 1 | 2 | 2 |
| 解決後冷卻 | 10 秒 | 0 秒 | 0 秒 |
| 健康度損耗 | 每攻擊每秒 0.15 | 每攻擊每秒 0.25 | 每攻擊每秒 0.35 |
| 提示 | 3 級，免費 | 2 級，免費 | 2 級，每級 -3 分 |
| 輔助 | 中文日誌註解、關鍵詞高亮、來源 IP 排行、診斷四步 | 同左 | 不提供以上輔助 |
| 誤操作扣分 | 扣分減半並四捨五入 | 照常 | 照常 |
| 速度獎勵 | 20 分起，每 6 秒減 1 分 | 20 分起，每 4 秒減 1 分 | 20 分起，每 3 秒減 1 分 |

所有模式在沒有攻擊作用時，每秒回復 1 點健康度；「警告」只在資源有有效攻擊或健康度低於 50 時顯示（健康度低於 35 時顯示「異常」）。

### 練習模式

在開始畫面選「練習模式」。不顯示倒數、不會自動產生攻擊、不計分、不寫入排行榜；使用簡單模式的提示及診斷輔助。從頂部選單選擇攻擊並按「觸發攻擊」，設定會先重設為該攻擊的易受攻擊狀態。相同攻擊仍在進行時不可重複觸發。按「離開練習」返回開始畫面。

## 介面導覽

開始畫面提供 17 步互動導覽：頂部列、資源列表、狀態、事件通知、控制台選單、概覽監控、日誌查看、回報事件、8 個工具及提示／計分。導覽使用示範資料，不計時、不產生攻擊、不計分、不寫排行榜；可以直接試用工具。完成後以 `localStorage` 鍵 `cs_tour` 記錄，按鈕會顯示「已完成，可重溫」。

## 提示與工具

- 提示第 1 級說明徵狀，第 2 級指出工具及位置；簡單模式第 3 級列出具體設定。使用第 3 級會取消該攻擊速度獎勵，但解決分數仍保留。
- 每個工具有「這個工具做甚麼？」說明及「重設為預設值」按鈕；DNS 工具不提供重設，以免直接洩露答案。
- 解決攻擊後右下角會顯示處置原理通知，15 秒後自動消失，也可手動關閉。
- 安全組只支援 TCP；每條規則為 `{port, src}`。`0.0.0.0/0` 是全世界來源，CIDR 可限制來源網段。
- 常見埠速查表：

| TCP 埠 | 用途 | 建議 |
|---|---|---|
| 21 | FTP 檔案傳輸 | 建議關閉 |
| 22 | SSH 遠端管理 | 限制來源 IP |
| 23 | Telnet 明文登入 | 建議關閉 |
| 80 | HTTP 網頁 | 可對外開放 |
| 443 | HTTPS 網頁 | 可對外開放 |
| 3306 | MySQL 資料庫 | 只限內網 |

- 日誌「合併相同事件」預設關閉；可自行勾選，並會在切換資源及分頁後保留本局選擇。

## 計分

| 項目 | 分數 |
|---|---:|
| 正確回報攻擊 | +20 |
| 解決攻擊 | +30 |
| 速度獎勵 | 最多 +20；按所選難度逐段遞減 |
| 錯誤回報 | -5（簡單模式四捨五入減半為 -3） |
| 使用困難模式提示 | 每級 -3 |
| 誤擋／錯誤設定／停用日誌／伺服器離線 | 按情況 -5、-10 或 -25；簡單模式減半並四捨五入 |
| 結束健康度獎勵 | 平均健康度百分比 × 2 |
| 結束預算獎勵 | 剩餘預算 ÷ 10，向下取整 |
| 處理完本局全部 quota 攻擊 | +50（因健康度或預算耗盡而終止不發） |

設定錯誤在按「套用」時檢查；同一錯誤一次套用只扣一次，不會在每秒更新時重複扣分。普通及困難模式扣足下表分數；簡單模式按 0.5 倍計算並四捨五入。

| 工具／資源 | 錯誤設定 | 扣分 |
|---|---|---:|
| VPC 防火牆 | 已啟用封鎖且閾值低於 50 Mbps | -10 |
| 限流 | 已啟用且每用戶每分鐘上限低於 5 | -10 |
| 安全組 web-01 | TCP 80 或 443 未對全世界開放 | -10 |
| 安全組 api-gw | TCP 443 未對全世界開放 | -10 |
| 安全組 ai-bot | TCP 443 未允許 `10.0.0.0/16` 或全世界來源 | -10 |
| 安全組 db-01 | TCP 3306 未允許 `10.0.0.0/16` | -10 |
| 安全組 db-01 | TCP 3306 對全世界開放 | -10 |
| EIP web-01 | 解除 EIP | -10 |
| DNS | 沒有進行中的 DNS 劫持時，www 或 api 記錄不是正確 IP | -10 |
| 日誌 | 停用日誌 | -5 |
| 提示規則 | 輸入長度上限低於 100 字元 | -5 |
| 費用監察 | 預算低於 HK$20 且超額動作為停止服務 | -5 |
| 伺服器 | 健康度降至 0 | -25 |

提示不會顯示「答案」按鈕。回報錯誤及沒有阻止目前攻擊時會顯示提示訊息（困難模式隱藏沒有阻止攻擊的提示）。

## 排行榜與私隱

排行榜使用 `localStorage` 鍵 `cs_lb`，最多保留 300 筆，每頁顯示按分數排序的 Top 10。欄位包括暱稱、班別、種子、難度 `diff`、分數及日期。預設顯示全部難度及種子；可選難度，並勾選「只顯示同一種子」。舊記錄沒有 `diff` 時當作「困難」。若瀏覽器禁止存取本機儲存，會改用頁面記憶體並顯示提示；關閉頁面後後備資料會消失。

只記錄自訂暱稱、班別代碼及遊戲結果；不要輸入真實姓名或其他個人資料。所有使用者輸入在輸出至 HTML 前均經 `esc()` 轉義。

## 自訂參數

在 `index.html` 的 `<script>` 區段調整：

| 常數／物件 | 作用 |
|---|---|
| `GAME_SEC=300` | 遊戲時長（秒） |
| `START_BUDGET=400` | 起始預算（模擬港元） |
| `DIFF` | 難度 quota、攻擊間隔、同時上限、健康度損耗、提示、輔助及速度獎勵 |
| `ATK` | 攻擊目標、日誌、影響及修正判定 |
| `I18N['zh-Hant']`、`I18N['en']` | 繁體中文及英文介面字串 |

## 已知限制

- 排行榜只存於本機瀏覽器，不能跨裝置同步，也不能防止使用開發者工具修改分數。
- 指標、費用、流量及攻擊均為教學模擬，並非真實雲端服務行為或正式帳單。
- `file://` 或隱私模式可能禁止 `localStorage`；排行榜會退回記憶體，但頁面關閉後資料不保留。
- 介面提供繁體中文及英文；內容未能代表完整雲端網絡安全控制，Prompt Rules 只作概念示範。
- 跨瀏覽器及實體手機相容性仍需按 `log.md` 測試記錄確認。
