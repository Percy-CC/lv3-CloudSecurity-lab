# 雲端安全模擬器 (Cloud Security Simulator)

供香港中學高年級學生使用的雲端安全教學模擬器。學生扮演雲端管理員，在 10 分鐘內辨識並阻止隨機出現的網絡層及應用層攻擊。

> 本專案為教學用模擬器，介面參考阿里雲控制台的版面結構，與阿里雲沒有任何關係。所有流量、費用及攻擊均為模擬數字，沒有連接任何真實雲端服務。

## 學習目標

- 分辨網絡層 (VPC、防火牆、安全組、Port、NAT/EIP、DNS) 及應用層 (Rate Limiting、Logging、Prompt Rules、Cost Monitoring) 的安全措施。
- 透過監控圖表 (Dashboard) 及日誌 (Logs) 辨識攻擊徵狀。
- 根據攻擊類型選擇正確的防護工具。
- 理解最小權限、縱深防禦等原則。

## 部署到 GitHub Pages

1. 建立 GitHub repository。
2. 將 `cloud-security-simulator.html` 重新命名為 `index.html`，並上傳至 repository 根目錄。
3. 進入 Settings → Pages。
4. Source 選擇 Deploy from a branch，Branch 選擇 `main`，資料夾選擇 `/ (root)`，按 Save。
5. 等待數分鐘後，網址通常為 `https://<用戶名>.github.io/<repository 名稱>/`。

本機測試：直接用瀏覽器開啟 HTML 檔即可，不需要安裝任何軟件。

## 遊戲玩法

1. 在開始畫面輸入暱稱、班別代碼及種子 (Seed)，可選擇開啟教學模式。
2. 首頁列出 5 項雲端資源及其狀態：運行中、警告、異常、已離線。
3. 每 20–40 秒隨機出現一個攻擊，同時最多兩個。
4. 進入狀態異常的伺服器控制台，查看「概覽監控」及「日誌查看」。
5. 在「回報事件」選擇攻擊類型。
6. 在左側選單選擇正確工具，修改設定後按「套用」。
7. 遊戲結束後查看分數、攻擊回顧及排行榜。

### 種子 (Seed)

- 相同種子會出現相同的攻擊次序及出現時間。
- 課堂建議：全班使用同一個種子，方便比較分數。

### 計分

| 項目 | 分數 |
|---|---|
| 回報事件正確 | +20 |
| 回報事件錯誤 | -5 |
| 解決攻擊 | +30，另加速度獎勵（最多 +20） |
| 使用提示 | -3 / 次 |
| 設定不當造成誤擋或服務中斷 | -5 至 -10 |
| 伺服器離線 | -25 |
| 結束時：平均健康度 | 健康度百分比 × 2 |
| 結束時：剩餘預算 | 剩餘預算 ÷ 10（取整） |
| 處理完所有攻擊 | +50 |

## 攻擊與對應工具

| 層次 | 攻擊 | 目標 | 工具 |
|---|---|---|---|
| 網絡層 | DDoS 流量攻擊 | web-01 | VPC 防火牆 |
| 網絡層 | 埠掃描 | web-01 | 安全組 |
| 網絡層 | SSH 暴力破解 | web-01 | 安全組 |
| 網絡層 | 資料庫暴露於公網 | db-01 | EIP / NAT |
| 網絡層 | DNS 劫持 | dns-zone | 雲解析 DNS |
| 應用層 | API 濫發請求 | api-gw | 限流 (Rate Limiting) |
| 應用層 | Prompt Injection | ai-bot | 提示規則 (Prompt Rules) |
| 應用層 | 費用暴增 | ai-bot | 費用監察 (Cost Monitoring) |
| 應用層 | 敏感資料外洩 | ai-bot | 日誌設定 (Logging) |

## 排行榜與私隱

- 排行榜使用瀏覽器 `localStorage`，只儲存在該部電腦。
- 只記錄暱稱、班別代碼、種子、分數及日期，不收集真實姓名、電郵或登入資料。
- 不使用 cookie 追蹤。
- 清除瀏覽器資料會同時清除排行榜。

## 自訂參數

在 HTML 檔內的 `<script>` 頂部可調整：

| 常數 / 物件 | 作用 |
|---|---|
| `GAME_SEC` | 模擬時間（秒），預設 600 |
| `START_BUDGET` | 起始預算（模擬港元），預設 1000 |
| `ATK` | 各攻擊的影響、日誌及修正條件 |
| `I18N` | 介面文字，可新增 `en` 語言包 |

## 已知限制

- 排行榜不跨電腦同步，分數可被學生使用開發者工具修改。
- 尚未在多款瀏覽器及裝置上完整測試。建議先用 Chrome 或 Edge 測試。
- 尚未提供英文介面。
